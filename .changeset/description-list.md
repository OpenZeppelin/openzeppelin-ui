Add `DescriptionList`: label/value pairs rendered as a semantic description list (each label a term, each value its definition). Values can be any node, including kit components such as `AddressDisplay`. Empty values show a placeholder (`emptyValue`, default `—`) so the pair keeps its place. Values stack under their labels on narrow widths. For review and summary screens, `layout="stacked"` keeps each label above its value at every width, `columns` (`1` through `5`) lays the pairs out in columns on wider screens and falls back to one column on narrow ones, and `valueAlign="end"` aligns values to the end of their row. Side-by-side labels size to their content so long labels are not forced into a fixed third of the row. An item may set `span` to occupy the full row in a multi-column list. `dividers` (default `true`) draws horizontal rules between pairs in a single-column list; set it to `false` to drop those rules. Multi-column lists draw a vertical rule between columns instead.
