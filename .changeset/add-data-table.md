Add `DataTable` on the main `@openzeppelin/ui-components` entry: column-as-data (`DataTableColumn`, `DataTableAlign`, `DataTableSortValue`), an accessible native `<table>` (`DataTableProps`, `DataTableName`) with Role Manager–family default chrome (rounded bordered card, muted header band, compact cells, row hover) and a sticky header by default (`stickyHeader`, opt out with `false`; header-cell tokens `sticky top-0 z-20` plus opaque `color-mix` of `--muted` 50% over `--card`; no-op on unbounded tables; not a virtualization option). A `caption` is visually hidden (`sr-only`) by default; show it with `captionClassName="not-sr-only"` or prefer `aria-labelledby`. Sorting (`DataTableSortState`, `DataTableSortDirection`) plus optional table-wide `formatSortButtonName` (`DataTableSortButtonNameInfo`: `{ columnName, direction: 'asc' | 'desc' | 'none' }`; omitted English `Sort by {name}`; blank return fail-closed with `sort:empty-name`). Client and server pagination (`DataTablePagination`, `DataTableClientPagination`, `DataTableServerPagination`, `DataTablePaginationPlacement` `'outside' | 'inside'` default `'outside'`, `DataTablePaginationStatusInfo` with `totalKnown` and nullable totals) including numbered page buttons (bounded window, ellipsis, `aria-current="page"`) plus Previous/Next with decorative lucide chevrons (`aria-hidden`; labels unchanged); optional `pagination.className` / `hideStatus`; optional server `totalCount` / `hasNextPage` when the total is unknown (omitted `totalCount` is silent). Opt-in row virtualization (`virtualized`, `DataTableVirtualization`, `DataTableVirtualizationHandle`, `DataTableScrollToAlign`, `DATA_TABLE_DEFAULT_ESTIMATE_SIZE` 64, `DATA_TABLE_DEFAULT_OVERSCAN`, `DATA_TABLE_DEFAULT_VIRTUALIZED_MAX_HEIGHT`), infinite scroll (`DataTableInfiniteScroll`), kit-owned row selection (`DataTableSelection`, `DATA_TABLE_SELECT_COLUMN_ID`, nested `selectedKeys: ReadonlySet<string>` + `onSelectionChange`, identity via `getRowKey`, injected select column default `w-12` then `columnClassName`), and consumer composition (`toolbar` ReactNode inside `data-table-frame`, `getRowClassName` on painted data rows). Typed `pagination` vs `infiniteScroll` is exactly-one-of (`DataTableLoadStrategy`, exported); untyped both-props still pager-win. Header select-all is tri-state over current body-row keys (not `selectedKeys.size === rows.length`). Internal `chrome.ts` tokens and selection helpers are not exported. Kit `Checkbox` now shows a minus glyph for `checked="indeterminate"`. Adds runtime dependency `@tanstack/react-virtual`. There is no `./data-table` subpath. GitHub CI now runs the components Chromium suite (`test:browser`) after jsdom.
