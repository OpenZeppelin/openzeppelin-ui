Add `DataTable` on the main `@openzeppelin/ui-components` entry: column-as-data (`DataTableColumn`, `DataTableAlign`, `DataTableSortValue`), an accessible native `<table>` (`DataTableProps`, `DataTableName`) with Role Manager–family default chrome (rounded bordered card, muted header band, compact cells, row hover) and a sticky header by default (`stickyHeader`, opt out with `false`; header-cell tokens `sticky top-0 z-20 bg-muted`; no-op on unbounded tables; not a virtualization option). A `caption` is visually hidden (`sr-only`) by default; show it with `captionClassName="not-sr-only"` or prefer `aria-labelledby`. Sorting (`DataTableSortState`, `DataTableSortDirection`), client and server pagination (`DataTablePagination`, `DataTableClientPagination`, `DataTableServerPagination`, `DataTablePaginationStatusInfo` with `totalKnown` and nullable totals) including numbered page buttons (bounded window, ellipsis, `aria-current="page"`) plus Previous/Next; optional server `totalCount` / `hasNextPage` when the total is unknown. Opt-in row virtualization (`virtualized`, `DataTableVirtualization`, `DataTableVirtualizationHandle`, `DataTableScrollToAlign`, `DATA_TABLE_DEFAULT_ESTIMATE_SIZE` 64, `DATA_TABLE_DEFAULT_OVERSCAN`, `DATA_TABLE_DEFAULT_VIRTUALIZED_MAX_HEIGHT`), infinite scroll (`DataTableInfiniteScroll`), and opt-in kit-owned row selection (`DataTableSelection`, `DATA_TABLE_SELECT_COLUMN_ID`, nested `selectedKeys: ReadonlySet<string>` + `onSelectionChange`, identity via `getRowKey`). Header select-all is tri-state over current body-row keys (not `selectedKeys.size === rows.length`). Internal `chrome.ts` tokens and selection helpers are not exported. Kit `Checkbox` now shows a minus glyph for `checked="indeterminate"`. Adds runtime dependency `@tanstack/react-virtual`. There is no `./data-table` subpath. GitHub CI now runs the components Chromium suite (`test:browser`) after jsdom.
